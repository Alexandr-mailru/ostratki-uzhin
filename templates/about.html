О проекте

«{{ site_name }}» — демо-сервис для портфолио: из продуктов в холодильнике подбираются рецепты.

Как пользоваться

  1. Отметьте продукты или выберите быстрый набор.
  2. Нажмите «Найти рецепты» — сортировка по % совпадения.
  3. Фильтруйте: «Всё есть», «До 30 мин», только локальная база.
  4. Сохраняйте в избранное и скачивайте PDF.

Стек

  • Backend: Python 3.12, Django 5.2, SQLite
  • Frontend: HTML, CSS, JavaScript, Bootstrap 5
  • Интеграции: Spoonacular Food API, xhtml2pdf
  • Деплой: Gunicorn, WhiteNoise, Render

База данных

69 продуктов с фото и 31 рецепт на русском. Без API-ключа работает локальная база; с ключом Spoonacular — расширенный поиск.

python manage.py seed_catalog --cache-photos
