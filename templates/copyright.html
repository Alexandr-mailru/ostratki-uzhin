Авторские права и источники контента

Соответствие законодательству РФ (в т.ч. ч. IV ГК РФ об авторском праве).

1. Код и дизайн проекта

Исходный код, вёрстка и демо-рецепты в локальной базе созданы автором портфолио для учебных целей. Копирование кода — с указанием авторства, если иное не согласовано.

2. Рецепты Spoonacular API

Часть рецептов, изображений и инструкций загружается через Spoonacular Food API. Права на такой контент принадлежат Spoonacular и/или первоначальным правообладателям. На странице рецепта указывается ссылка на источник. Использование — в рамках условий API и закона РФ (включая добросовестное цитирование и указание авторства).

3. Фото продуктов

Миниатюры ингредиентов загружаются с CDN Spoonacular и кэшируются локально. Для отдельных позиций используются фото с Wikimedia Commons (лицензии CC). Права на изображения принадлежат соответствующим правообладателям.

4. Датасет RecipeNLG (опционально)

Команда load_recipes может загружать рецепты из датасета RecipeNLG (лицензия MIT). Автор портфолио не гарантирует отсутствие совпадений с коммерческими изданиями в сторонних данных; для публичного демо рекомендуется команда seed_demo с оригинальными русскими текстами.

5. Шрифты и библиотеки

  • Bootstrap — MIT License;
  • Font Awesome Free — Icons: CC BY 4.0, Fonts: SIL OFL 1.1, Code: MIT;
  • Django и зависимости — см. соответствующие лицензии в requirements.txt.

6. Претензии правообладателей

Если вы считаете, что материал нарушает ваши права, свяжитесь с автором проекта (контакт в README). Материал будет рассмотрен и при необходимости удалён в разумный срок.
